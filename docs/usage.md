# Как пользоваться

## Панель

- **Разделы.** «Вакансии» (основная работа), «Подработка», «Телеграм», «Сборы и логи», «Настройки».
- **Вкладки ленты.** «Новые», «Просмотренные», «Отклик», «Не подходит». Каждая вакансия находится ровно в одной.
- **Фильтры.** Площадка, направление, «зарплата указана», «без опыта» и поиск по названию, компании и описанию.
- **«Не подходит»** убирает вакансию из ленты одним нажатием. Несколько секунд можно выбрать причину или отменить действие.
- **Старые вакансии.** В группе «Раньше» есть кнопка, которая переносит всё без решения старше 14 дней в «Не подходит» с причиной «устарела».
- **Горячие клавиши.** `J` / `K` переход, `Enter` подробнее, `1` `2` `3` статус, `O` открыть, `/` поиск.
- **Тема** светлая или тёмная, по настройкам системы.

## Настройки

Все файлы лежат в `config/`, но их проще менять в панели.

| Раздел | Что настраивается |
|---|---|
| Запросы hh | поисковые запросы и направления |
| Площадки | слова для Habr Career, Geekjob, getmatch |
| Телеграм-каналы | каналы и ключевые слова |
| Отсев | правила, по которым вакансия скрывается |
| Пометки | метки на карточках по словам в описании |
| Мои навыки | подсветка навыков в описании вакансии |
| Параметры | регионы, паузы между запросами, глубина первого сбора |

Папка `config/` не попадает в репозиторий. Образец лежит в `config.example/`.

## Как устроен сбор

- По каждому запросу запоминается время последнего успешного сбора, следующий запуск берёт вакансии с этого момента. Если сбор упал, период повторится.
- hh.ru читается через страницы сайта, как в браузере. Берутся только точные совпадения, «похожие» вакансии отбрасываются.
- На Habr Career, Geekjob и getmatch слова ищутся локально в названии, навыках и описании, потому что поиск самих площадок нечёткий или отсутствует.
- Повторы (та же компания и похожее название, в том числе на разных площадках) помечаются и не показываются.
- Закрытые вакансии скрываются из ленты, но остаются в базе.

```
src/jobauto/
  sources/        hh, Habr Career, Geekjob, getmatch, Telegram
  runner.py       один запуск сбора
  exclude.py      правила отсева
  duplicates.py   поиск повторов
  maintenance.py  очистка базы
  api.py          локальный сервер панели (FastAPI)
  static/         панель (HTML, CSS, JS без сборки)
config.example/   настройки по умолчанию
tests/            тесты и сохранённые страницы площадок
```

## Где лежат данные

- `config/` личные настройки.
- `data/jobs.db` база с вакансиями, постами, статусами и заметками.
- `data/backups/` копия базы перед каждым сбором, хранятся последние 3. Чтобы восстановить, закройте панель и замените `data/jobs.db` файлом из этой папки.
- `dumps/ГГГГ-ММ-ДД.md` новое за каждый сбор.

Папки `config/`, `data/` и `dumps/` перечислены в `.gitignore`.

## Очистка

При каждом сборе база чистится, чтобы не разрастаться.

- У вакансий «Не подходит» и у вакансий без решения старше 30 дней удаляются описания. Название, компания, ссылка и причина остаются, поэтому такая вакансия заново не соберётся.
- Вакансии с откликом или заметкой не трогаются.
- Логи и пробные выгрузки старше 30 дней удаляются.

## Если hh.ru не отвечает

Запустите `check.bat` или `python -m jobauto check`. Проверка покажет ответы площадок и сохранит отчёт в `data/logs/`.
